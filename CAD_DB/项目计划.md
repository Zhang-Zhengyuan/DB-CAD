这是一个CAD数据库储存项目。

我们的最终目标是把前端和后端分离开，让后端提供储存服务，通过FastAPI暴露给前端。
最终多人能够在不同的电脑上建模，然后远程保存，如果有更改，会同步给所有人，实现多人共同编辑。

## 项目分期

### Phase 1（已完成）后端基础设施搭建
- 新建 Python FastAPI 后端目录：`CAD_DB/backend`
- 建立版本化数据模型：`Project`、`ModelVersion`
- 提供核心 REST API：
  - 创建项目
  - 查询项目
  - 保存模型版本
  - 获取最新版本
  - 分页查询历史版本
- 增加并发协作基础能力：
  - `base_version` 冲突检测
  - WebSocket 项目级变更广播
- 提供基础测试与运行说明文档

### 当前架构校准（已完成）
- 你指出的方向是正确的：最终应由 FastAPI 作为统一后端服务层，前端 Qt 仅通过 API 访问。
- 已补上关键缺口：FastAPI 已支持直接使用 Neo4j 作为存储后端（不再仅限 SQLite）。
- 现有 EXE 已支持 FastAPI 存取模式，可通过 HTTP 保存/加载远程版本。

### Phase 2（下一步）与现有 EXE 集成
- 在现有 CAD 客户端增加后端连接配置（已完成）
- 接入保存/拉取模型接口（已完成）
- 接入 WebSocket 推送并实现本地刷新策略（进行中）

### Phase 3（下一步）协同编辑增强
- 增量变更模型（diff/operation）
- 用户与权限体系
- 历史回滚与审计日志

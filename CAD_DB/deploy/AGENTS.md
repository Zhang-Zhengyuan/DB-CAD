# 部署补充规则

继承根与客户端中适用规则；部署事实入口为 `../DEPLOYMENT.md`。

- 在现有 lib/ 职责内修改配置、Docker、进程与打包；保持 cmd 包装入口和 PowerShell 参数兼容。路径相对脚本解析，不硬编码某位成员盘符。
- 密码由配置/环境管理；不在日志、进程说明、Issue/PR 中公开。不能把已配置密码替换为示例默认值。
- 新后台 Start-Process 使用 Hidden，除非用户要求可见交互窗口。停止仅针对可识别的本次启动进程，不按泛化进程名杀服务。
- PrepareOnly 和正常启动不得顺手重置数据。reset 脚本与删除 volume 需要用户明确授权准确对象；禁止把清库写成测试自动前置。
- 核验打包包含后端静态资源和匹配运行时；在独立输出目录验证，不能依赖源码目录残留 DLL。PrepareOnly 不等于全栈启动验收。

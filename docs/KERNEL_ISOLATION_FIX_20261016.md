# Push 故障修复与内核隔离复查（2026-10-16）

## 故障原因

冷启动创建实体后直接序列化时，ACIS 返回 68017：`could not save, the units in Fileinfo must be valid`。序列化器依赖其他文件保存流程设置的进程全局 FileInfo；既有图测试在启动时预设 FileInfo，因此未发现这一缺陷。故障发生于客户端，与两端是否连接同一 FastAPI 项目无关。

适配层新增私有 SAT I/O helper，每次写入均显式设置单位、产品信息、当前运行内核支持的版本和序列文件选项；不再使用格式 2.0 保存新模型。临时文件通过 Qt 创建，Windows 使用宽字符路径打开，文件句柄和临时文件自动释放。错误信息保留实体 UUID 与内核原因。恢复失败或片段根类型/数量不匹配时清理恢复对象并拒绝应用。

## 本轮修复

- 当前树项改存稳定逻辑索引，消除 vector 扩容、删除后的悬空指针；重建树及显示控件时阻断反馈信号。
- clear 不重用逻辑索引，避免 pending change 指向另一实体。Push 按当前存活 UUID 修正删除记录，覆盖删除、撤销和重新加入。
- 本地撤销使用每个根的 SAT 备份恢复；远端更新清除旧构造配方，重建反向依赖。远端实体标为导入对象。
- 多结果运算按组重建，替换既有结果；依赖按前置关系更新并防止递归环。布尔运算检查输入数量、重复输入及既有依赖，显式管理输入所有权。
- 未完成样条草稿提供明确的保存/Push 错误；草稿显示跳过网格化，控制点绘制检查空行。Escape 取消交互，保留文档。
- 打开 FastAPI 项目在成功重建前保留旧文档；关闭清理失败时拒绝退出，防止提前终止内核。
- PostgreSQL 单次加载回调不再断开永久错误处理器。

## 隔离复查结论

业务入口（Window、MainWindow、协作 HTTP 客户端、OpenGL 消费端）通过 `GeometryKernel` 操作会话句柄、值类型及网格 DTO，没有直接调用 ACIS SDK。原生实体、造型、SAT I/O、粗细混合图编码和原生对象释放由 `DbcadAcis` 适配目标承担。新增回归复用实际客户端源码，不以 mock 替代几何内核。

隔离达到当前接口边界，但不能据此宣称任意模型都没有缺陷，或更换内核已无需额外开发：

1. SAT 和细粒度 JSON 的具体几何语义仍是 ACIS 格式，替换内核必须实现转换或保留历史读取器；SAT 保留不等于所有输入都已证明跨内核等价。
2. 旧版 Neo4j 增量存取仍通过兼容适配入口使用 ACIS 历史流；本轮未连接用户数据库执行这些菜单。
3. 未接入第二个实际 CAD 内核，因此接口的跨内核适配能力仍需在第二实现中验证。当前明确提供的编辑变换是平移。
4. 构建仍有既有 SDK 弃用/编码警告及 OpenGL double→float 警告。本轮没有将警告误记为编译失败。

## 可重复验证

Windows 配好依赖与本地许可后执行：

```powershell
.\scripts\tests\run-client-regression.ps1 -Configuration Release
.\scripts\tests\run-client-regression.ps1 -Configuration Debug
```

脚本构建正式客户端与独立 regression 可执行文件，启动随机本机端口 FastAPI 测试服务，结束后清理该服务。测试服务复用项目真实 API 与测试 MemoryStore，不接触用户数据库。日志在 `artifacts/`。客户端窗口会短暂出现以验证实际 OpenGL 生命周期。

检查范围：冷启动首次/连续序列化、31 种预设几何的混合往返、SAT 恢复、句柄失效、Boolean 输入保留、损坏组件整体拒绝、中文临时路径；实际客户端 Push/Pull、WebSocket 通知、移动、撤销、删除撤销、清空再加、稳定选择、多结果依赖重建及版本冲突。

另执行现有 `graph_roundtrip_tests 18`，18 组全部通过（含体积、包围盒、拓扑数量、复杂曲面/曲线与粗细回退）。后端 `python -m pytest -q -m 'not integration'`：44 通过、13 个外部服务集成用例未运行。

本轮 HTTP 联调验证真实 Qt 客户端、真实 ACIS 和 FastAPI 路由；持久化使用独立内存仓库，不能将其描述为已验证用户 Neo4j 部署。

最终结果：Release、Debug 正式客户端构建成功；两个配置均通过 76 项内核检查和 25 项实际客户端/HTTP/WS/窗口检查。现有 18 组图往返测试无失败，后端 44 项通过。打包目录 client 的可执行文件和匹配运行库已更新，原配置保留，旧二进制备份在本地 artifacts/package-before-sat-fix。
